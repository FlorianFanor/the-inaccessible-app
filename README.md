# The Inaccessible App

A project designed to explore, demonstrate, and improve accessibility challenges in modern web applications.

Please have a try by follwing the instructions on: https://florianfanor.github.io/the-inaccessible-app/

---

## ✨ Project Overview

**The Inaccessible App** aims to:

- Highlight common accessibility issues in web development
- Serve as an educational tool for developers and designers
- Provide examples of both poor and proper accessibility practices
- Help teams audit and fix accessibility problems
